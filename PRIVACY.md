# Privacy Policy

_Last updated: 11 November 2026_

This policy covers the **Claude Executive Suite** plugin (`executive-suite`) and the skills in this repository, [Neyam-OpenSc/claude-skills-executive-suite](https://github.com/Neyam-OpenSc/claude-skills-executive-suite).

## Summary

The plugin collects no data, sends no data anywhere, and runs no code. It is a set of written instructions (Markdown `SKILL.md` files) that tell Claude how to help you.

## What the plugin contains

- Markdown skill instructions (`SKILL.md` files) and documentation
- JSON manifest files (`.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`)
- Images (the plugin icon and the README banner)

It contains **no** scripts, programs, MCP servers, connectors, tracking, analytics or API keys.

## Data we collect

**None.** The maintainers of this plugin do not run any server or service, and we do not receive, collect, store or have access to anything you type, upload or generate while using the skills.

## Data sent to third parties

**None.** No skill sends data to any outside service.

Some skills ask Claude to cite sources **if** your Claude setup already has web search enabled. That search is performed by Claude's own built-in tools, under your existing agreement with Anthropic, not by a service added by this plugin.

## Files written on your device

Some skills ask Claude to save notes to a `company/` folder **inside your own project**, for example `company/profile.md`, `company/pricing.md`, `company/finance.md`, `company/decisions.md` and `company/weekly/`. These files:

- are written on your device by Claude, at your request;
- contain only what you provided or what Claude produced for you;
- are never sent to the plugin maintainers;
- are fully under your control, and you can edit or delete them at any time.

If you enter personal data into a skill (for example customer or job-candidate names), it may be written to these local files. Avoid entering personal data you don't need, and handle any you do enter in line with the laws that apply to you.

## Your use of Claude

When you use these skills, your conversations are processed by Claude under Anthropic's own terms and privacy policy, which this plugin does not change. See [Anthropic's Privacy Policy](https://www.anthropic.com/legal/privacy).

## Children

The plugin is intended for founders and businesses, and is not directed at anyone under 18.

## Changes to this policy

Any changes will be published in this file, with a new "Last updated" date. The full history is available in this repository's commit log.
