# Team Playbook — Chaining Skills

The real power is sequencing skills like an executive team meeting.

## Pattern 1: Idea → Revenue (the founder sprint)

```
startup-validator  →  prompt-to-profit  →  cfo-agent (unit economics)  →  launch-war-room
```

1. **startup-validator**: is the idea worth anything?
2. **prompt-to-profit**: what's the smallest sellable version?
3. **cfo-agent / unit-economics-expert**: does the math work?
4. **launch-war-room**: ship it in 7 days.

Prompt: *"Use agent-team-orchestrator to take my idea from validation to a 7-day launch plan."*

## Pattern 2: Churn emergency

```
customer-success-manager  →  customer-psychology-expert  →  pricing-strategist  →  decision-architect
```

Diagnose → understand the psychology → fix pricing → decide with a clear head.

## Pattern 3: The weekly board meeting (solo founder)

Every Monday:

```
solo-founder-os  →  boardroom-simulator (on your top decision)
```

Every Friday:

```
chief-of-staff (review)  →  financial-controller (books)  →  content-director (next week)
```

## Pattern 4: Competitor attack plan

```
competitor-intel-analyst  →  brand-strategist  →  cro-optimizer  →  growth-hacker
```

Find their weakness → reposition → convert better → scale acquisition.

## Rules for chaining

- Never chain more than 5 skills — depth beats breadth.
- Use `agent-team-orchestrator` to sequence automatically.
- End every chain with **decision-architect** or **chief-of-staff** to convert analysis into action.
